# Invitación de graduación · Joselyn Ortiz

Página estática adaptable a celular, con foto, botón de apertura y confeti, cuenta regresiva, ubicación en Google Maps, descarga de calendario y botón para compartir el enlace una vez publicada.

Fecha utilizada: 7 de noviembre de 2026, 15:00, hora del centro de México (UTC−6). No hay formulario de confirmación ni almacenamiento de datos de invitados.

## Publicar en GitHub Pages

1. Inicia sesión en GitHub y crea un repositorio público llamado `graduacion-joselyn`.
2. Sube el contenido de esta carpeta a la raíz del repositorio, conservando la carpeta `assets`. `index.html` debe quedar en la raíz.
3. En el repositorio, abre Settings → Pages. En Build and deployment selecciona Deploy from a branch, rama main y carpeta / (root). Guarda.
4. Cuando termine el despliegue, GitHub mostrará el enlace de la invitación en esa sección. El enlace tendrá el formato `https://TU-USUARIO.github.io/graduacion-joselyn/`.

La foto y la ubicación serán accesibles públicamente al publicar, como parte de la invitación. Las fuentes de Google son opcionales: la página conserva fuentes de respaldo si no hay conexión con Google Fonts. El resto de los archivos se aloja en el mismo sitio.

## Cambiar la fecha

Actualiza los textos en index.html, la fecha al inicio de app.js y DTSTART en graduacion-joselyn.ics. La hora UTC del calendario es 21:00, equivalente a 15:00 en Jocotitlán.
